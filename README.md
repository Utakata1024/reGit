# reGit

**PythonでGitを再発明するプロジェクト**

## 概要

reGitは、バージョン管理システム「Git」の基本的な機能をPythonで一から実装するプロジェクトです。

Gitの内部構造や仕組みを理解することを目的としています。

## 目的

- Gitの内部構造や動作原理を理解する
- バージョン管理システムの仕組みを学ぶ
- Pythonを使ったCLIツールの開発を経験する

## 実装予定の機能

| コマンド | 機能 |
|---|---|
| `regit init` | リポジトリの初期化 |
| `regit add` | ファイルをステージング |
| `regit commit` | 変更履歴の記録 |
| `regit log` | コミット履歴の表示 |
| `regit status` | ファイルの変更状態を確認 |

※ 実装する機能は開発の進行に応じて変更する可能性があります。
